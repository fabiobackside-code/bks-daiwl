# Security / Segurança

The skill only reads your sources and writes to `<vault>/.daiwl/`. If you find behaviour that writes elsewhere,
leaks content from your sources, or runs untrusted code, please **do not open a public issue**.

Report privately through GitHub: **Security → Report a vulnerability** on this repository.

A skill só lê suas fontes e escreve em `<vault>/.daiwl/`. Se encontrar comportamento que escreve fora disso, vaza
conteúdo das fontes ou executa código não confiável, **não abra issue pública**: use **Security → Report a
vulnerability** neste repositório.
