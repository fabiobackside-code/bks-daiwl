# BKS-DAIWL — Don't Accept It Without Learning

![version](https://img.shields.io/badge/version-1.0.0-informational) ![languages](https://img.shields.io/badge/lang-en%20%7C%20pt--BR-blue)

🇧🇷 [Leia em português](README.pt-BR.md)

A **personal maintainability** skill for AI coding agents. It measures how well *you* will be able to
maintain code generated by AI (Claude Code, Copilot, Cursor, MCP agents), by comparing the fundamentals the AI
applied with the ones you master, have learned, or decided from experience — and teaches you the gap using the
generated code itself as the example.

## The loop

```
 your sources ──index──▶ Canon Index
 (vault, repos, papers, links)   │
 AI code ──analyze───────────────┤──▶ score.md/html         (PMS 0–100, divergences, gaps)
                                 │──▶ fundamentals.md/html  (each fundamental with a real snippet,
                                 │                            how to study it, primary sources)
                                 ▼
          learned <concept>    ──▶ .daiwl/learnings/   ──▶ score goes up
          experience "<note>"  ──▶ grounded, negotiated, saved as a light ADR ──▶ used next time
```

The LLM **classifies**; `skills/bks-daiwl/scripts/daiwl.py` **scores** — same input, same score, auditable.

## Install

**Claude Code** — `git clone https://github.com/fabiobackside-code/bks-daiwl && cp -r bks-daiwl/skills/bks-daiwl ~/.claude/skills/` (global) or `.claude/skills/` (project).
**Claude.ai / Desktop** — install the `.skill` file from [Releases](https://github.com/fabiobackside-code/bks-daiwl/releases).
**GitHub Copilot (agent mode)** — `cp -r bks-daiwl/skills/bks-daiwl .bks-daiwl && mkdir -p .github/prompts && cp bks-daiwl/skills/bks-daiwl/adapters/copilot/daiwl.prompt.md .github/prompts/` → `/daiwl`.
**Cursor** — `cp -r bks-daiwl/skills/bks-daiwl .bks-daiwl && mkdir -p .cursor/rules && cp bks-daiwl/skills/bks-daiwl/adapters/cursor/daiwl.mdc .cursor/rules/`.

Python 3.9+ (standard library only) for deterministic scoring; without it the agent computes by hand and shows the math.

## First run

No vault? The skill creates an Obsidian-compatible one and runs a short interview to seed your concepts:
```bash
python skills/bks-daiwl/scripts/daiwl.py init --vault ~/DAIWL-Vault --create --lang en
```
Already have one? Point to everything:
```bash
python skills/bks-daiwl/scripts/daiwl.py init --vault ~/Obsidian/Dev --lang en \
  --source repo:~/src/wallet-apis:own \
  --source repo:~/src/copilot-poc:ai \
  --source papers:~/Documents/papers \
  --source links:~/Obsidian/Dev/References/links.md
python skills/bks-daiwl/scripts/daiwl.py sources ls
```
Source types: `vault`, `notes`, `repo` (authorship `own` | `mixed` | `ai` required), `papers`, `links`, `url`.
The skill **only reads** sources and writes only to `<vault>/.daiwl/`. AI-authored repos never count as proof of mastery.

## Commands

| Command | Example |
|---|---|
| `init` | `daiwl init` |
| `sources` | `daiwl sources add papers:~/papers` |
| `index` | `daiwl index` |
| `analyze` | `daiwl analyze ./src` |
| `learned` | `daiwl learned "Outbox Pattern" "Result Pattern"` |
| `experience` | `daiwl experience "Generic repository leaked IQueryable in a past project; I prefer one repository per aggregate"` |
| `version` | `daiwl version` |

Portuguese equivalents work too (`indexar`, `analisar`, `aprendi`, `experiencia`, `fontes`, `versao`).

## Score

`PMS = Σ(impact × factor) / Σ(impact) × 100`, impact = structural weight × (1 + ln occurrences).
Declared-only concept 0.70, gap 0, divergence −0.5, unfounded AI improvisation −0.25. See `skills/bks-daiwl/references/score.md`.

## Versioning

SemVer, see `CHANGELOG.md`. Every report stores the skill version and the score formula version; deltas across
different formula versions are not shown as progress.

## Known limits

- Classification is done by an LLM; two runs may differ by one or two fundamentals. `findings.json` is kept so you
  can review it before scoring.
- The index only sees what is written. If you master something you never wrote down, use `learned` or add a note.
- "Grounded" depends on the catalog and, with web access, primary sources. Extend the catalog with your own books.
